Blueprint Nodes

Graph Introspection Nodes

Classes
USimFlowAsset, USimFlowNode and its subclasses
Get a reference
Get Flow Asset on the component, or Get Template / Get Active Nodes on an instance
Target pin
The asset or the node
Category
SimFlow, SimFlow | Authoring, SimFlow | Node

Use them for: editor utilities, custom debug overlays, and flows generated at runtime.

The narrowest corner of the API. Most projects never need it.

Nothing here places a node in a graph. These read and write the graph nodes an asset already contains, or build new ones programmatically.

Reading an asset

USimFlowAsset, queries
NodeReturns
Get Display Name TextFlow Display Name, falling back to the asset name.
Get Node CountHow many nodes the asset holds.
Get Entry NamesEvery Start node's entry name.
Find Node By GuidOne authored node, or null.

Get Entry Names is the useful one. Populate a dropdown with it and you have a scenario picker that cannot offer an entry which does not exist, which beats a text field where a typo silently starts nothing.

Get Node Count counts every node, not just tasks. For a progress denominator use Get Progress on the instance instead.

Validating

It reports what a designer should know about: no entry node, links pointing at nodes that no longer exist, task nodes with no task assigned, nodes nothing can reach.

Empty errors means the flow will run. Warnings can still be real problems that happen not to be fatal.

Worth running over the whole project before a build

The same checks run in the graph editor, but only for the asset that is open. An editor utility widget looping every flow asset and calling Validate Flow catches the one nobody opened this month.

Node introspection

USimFlowNode, on any node
NodeReturns
Get Flow InstanceThe instance running this node.
Get BlackboardShortcut to that instance's blackboard.
Is Node ActiveWhether it is currently executing.
Get Node Active TimeSeconds since it activated.
On specific node types
NodeOnReturns
Get TaskTask nodeThe task object.
Get Remaining TimeTask nodeSeconds left on the time limit.
Get Child InstanceSub Flow nodeThe child flow's instance.

Get Node Active Time resets each time the node activates, so a re-entered Loop starts counting again.

Get Child Instance is how you reach into a running sub-flow: its blackboard, its active tasks, its mistakes. A Sub Flow child has its own instance, and this is the only handle on it.

Trigger Output

It pushes execution out of a named output pin, exposed so a Blueprint node subclass can drive itself. Stay Active left off deactivates the node afterwards, which is what almost everything wants. Leave it on for a node that fires an output and keeps running, the way Parallel does.

Only call this on a node you wrote

Triggering an output on a built-in node from outside puts the flow in a state that node does not expect. Nothing stops you, and nothing warns you.

Building a flow at runtime

USimFlowAsset, authoring
NodeReturns
Add NodeThe new node, typed to the class you passed.
Remove Node
Connect Nodesbool. Wires From.FromPin into To.ToPin.
Disconnect Nodesbool

For generating scenarios from data: a procedure defined in a spreadsheet, a randomised assessment, a flow assembled from a difficulty setting.

Build against a fresh asset, not one on disk

These change the asset itself. Editing the one your project ships modifies it for every flow using it, and in the editor that change can be saved over your authored graph.

Pin names have to match what the node actually declares. Connect Nodes returns false for a pin that does not exist, and that false is the only signal you get. Call Validate Flow when you have finished assembling; it is far easier to read than a flow that starts and quietly does nothing.

A scenario picker from entry names

  1. Get Flow Asset from the component.
  2. Get Entry Names.
  3. Build one button per name, labelled with it.
  4. On click, Start Flow From Entry with that name.

When it misbehaves

SymptomCause
Find Node By Guid returns null for a node that existsYou are searching the asset with a runtime node's Guid, or the reverse. Find Runtime Node on the instance is the live side.
Get Task returns null on a Task nodeNo task is assigned. Validate Flow reports this.
Connect Nodes returns false and nothing is loggedA pin name does not match. Check the node's declared pins.
Runtime changes to an asset do not affect the running flowNodes are duplicated into the instance when the flow starts. Restart to pick them up.
A runtime-built flow starts and immediately stopsNo entry node, or the entry's Out is unwired. Validate Flow catches both.
Get Node Active Time keeps resettingThe node is being re-entered, which is normal inside a Loop.
