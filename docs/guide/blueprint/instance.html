Blueprint Nodes

Flow Instance Nodes

Class
USimFlowInstance
Get a reference
Get Flow Instance on the SimFlow Component
Target pin
The instance
Category
SimFlow, SimFlow | Control, SimFlow | Mistakes, SimFlow | Save

Use them for: what the component does not surface — the list of active nodes, the mistake record, whether a particular event has fired.

The instance is the running copy of a flow asset. It owns the duplicated nodes, the blackboard, the mistake log and the set of raised events. Most projects never touch it, because the component forwards the things you usually want and does so safely.

Instance functions do not check authority

Component functions check authority and route client calls to the server. These do neither: they act immediately on whichever machine runs them. With Replicate Flow on, calling Pause Instance on a client pauses the client's mirror, your UI updates, and the next server refresh silently undoes it.

Prefer the component for anything that changes state
Instead ofCall on the component
Pause Instance / Resume InstancePause Flow / Resume Flow
Stop InstanceStop Flow
Retry Active TasksRetry Current Task
Skip Active TasksSkip Current Task
Fail Active TasksFail Current Task
Raise EventSend Event, or Broadcast Flow Event

The read-only nodes further down are safe anywhere.

Lifecycle and player controls

USimFlowInstance, lifecycle
NodeReturnsNotes
Start InstanceboolEntry Name of None starts from the first entry.
Pause InstancePaused nodes stop ticking.
Resume Instance
Stop InstanceEnds the flow reporting Aborted, not Failed.
Retry Active Tasksint32How many were restarted.
Skip Active Tasksint32How many were skipped.
Fail Active Tasksint32How many were failed.

The count is the useful part of the three control nodes. One flow can have several tasks running at once through Parallel, so "retry the current task" is really "retry all of them". A return of zero means nothing was eligible: no task is active, or every active task has Allow Retry off.

Retry and skip honour the per-task Allow Retry, Max Retries and Allow Skip fields. Fail does not ask permission.

Events

USimFlowInstance, event tags
NodeNotes
Raise EventRaises a tag on this instance only, then processes anything that unblocked. An invalid tag is ignored.
Was Event RaisedHas this tag fired at any point during the run?
Clear Raised EventsForgets all of them.

The raised set accumulates for the life of the instance and is never cleared for you. That is deliberate: it is what lets an Event Was Raised condition ask about something that happened five tasks ago.

A loop checking the same tag sees it raised forever

After the first pass the tag stays in the set, so the check passes on every subsequent pass whether or not anything happened. Call Clear Raised Events at the top of the loop body to re-arm it.

Matching follows the tag hierarchy in one direction. Raising Sim.Grab.Extinguisher makes Was Event Raised(Sim.Grab) true. Raising Sim.Grab does not make Was Event Raised(Sim.Grab.Extinguisher) true.

Mistakes

USimFlowInstance, the mistake record
NodeReturns
Record MistakeLogs Kind, Involved, Description, Severity and Task Id.
Get MistakesEvery mistake, in order.
Get Mistake Countint32
Get Mistakes Of KindFiltered by tag, with optional child matching.
Clear MistakesEmpties the array.

Record Mistake also bumps the Mistakes blackboard key, so conditions written against that counter keep working while the array holds the richer record a debrief screen needs.

Severity is an ESimFlowMatchQuality: No Match for something unrelated, Related (Near Miss) for the right family and wrong item. Getting this right is what lets a debrief say "you reached for the CO2 extinguisher" rather than "wrong object".

Clear Mistakes empties the array but does not reset the Mistakes blackboard key, so clear that separately if your conditions read it.

Get Owning Component walks up through parent instances, so a Sub Flow child returns the component running the whole tree rather than null.

Get Progress counts completed task nodes against every task node in the asset. Branches the trainee never took still count in the denominator, so a flow with a large optional section reports lower than it feels. It is a progress bar, not a measurement.

Get Active Task Nodes returning more than one entry means Parallel is running. Single-track tutorial UI should use Get Current Task, which gives you the first.

Dispatchers

Eleven events fire on the instance. Ten are mirrored onto the component, which is the better place to bind from because the component survives a restart and the instance does not. Two are worth coming here for.

Only on the instance
DispatcherCarriesWhy
On Event RaisedEvent Tag, PayloadThe component does not forward it.
On Mistake RecordedThe mistake structDrive live feedback the moment something goes wrong.

A new instance is built every time a flow starts. Bindings made to the previous one are gone after a restart, which is the main reason to prefer the component.

A debrief screen

Reading the run on On Flow Finished, while the instance is still valid:

  1. From the component, Get Flow Instance.
  2. Get Mistakes for the list, or Get Mistakes Of Kind with SimFlow.Mistake.WrongItem for one category.
  3. Get Elapsed Time into Format Seconds for a duration.
  4. Get Run State into Run State To Text for the outcome.
  5. Get Blackboard then Get Score for the score.

When it misbehaves

SymptomCause
Get Flow Instance returns nullThe flow has not started. The instance is created on start, not when the component is added.
A pause from a client reverts after a secondYou called Pause Instance instead of the component's Pause Flow.
Retry Active Tasks returns 0No task is active, or Allow Retry is off on the ones that are.
Was Event Raised is true when it should not beThe set is never auto-cleared. Call Clear Raised Events.
Get Progress jumps unevenlyIt counts task nodes in the asset, including branches this run skipped.
Bindings stopped firing after a restartThe instance was replaced. Bind to the component instead.
Get Mistake Count and the Mistakes key disagreeClear Mistakes empties the array without touching the key.
