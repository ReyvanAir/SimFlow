Blueprint Nodes

Zone and Identity Nodes

Library
USimFlowIdentityStatics
Also on
ASimFlowZone, which needs the zone actor on its target pin
Target pin
None for the identity statics
Category
SimFlow | Identity, SimFlow | Zone

Use them for: a highlight that only appears on the right object, a hint system, or an interaction that behaves differently depending on what the player is holding.

Tasks already do this judging for you. These nodes exist for the cases where your own Blueprint needs the same answer.

Identity

USimFlowIdentityStatics, reading an actor
NodeReturns
Get Identity TagsEvery identity tag on the actor.
Get Identity Display NameThe authored name, falling back to the actor's name.
Actor Has Identity Tagbool

Get Identity Tags reads the SimFlow Identity component first, then falls back to IGameplayTagAssetInterface. Actors from a GAS project answer correctly without a second component on them.

Get Identity Display Name is what your prompts should use. "Pick up the foam extinguisher" reads better than the actor label BP_Ext_Foam_2, and it stays correct when someone renames the Blueprint.

Grading against a query

USimFlowIdentityStatics, query matching
NodeReturns
Match Actor Against QueryNo Match, Related (Near Miss) or Exact Match.
Actor Satisfies Querybool, the yes-or-no form.

The middle value is the whole point of the enum. A CO2 extinguisher where a foam one was asked for is a different kind of wrong from a wrench, and your feedback can say so.

A null Instance pin breaks any query using a Blackboard Key

The pin may be null when the query uses no blackboard key. When it does use one, the query cannot resolve it and never matches. Nothing logs, so it looks like the actor is simply wrong.

Zone contents

ASimFlowZone, queries
NodeReturns
Get Contained ActorsEverything overlapping, settled or not.
Get Settled ActorsEverything put down and left alone.
Contains Actorbool
Is Actor Settledbool
Get Display Name TextThe zone's authored name.

The contained against settled split is the thing to get right. An actor the player is holding inside the zone is contained but not settled. Tasks judge on settled, which is why waving an extinguisher over the bay does not count as placing it.

Use contained for live feedback, such as highlighting the bay while something hovers over it, and settled for anything that decides an outcome.

Effective settle values

ASimFlowZone, what the current mode actually applies
NodeReturns
Get Effective Settle TimeStill-time the current mode requires.
Get Effective Settle SpeedSpeed limit the current mode applies. 0 means no check.
Get Effective Require DetachedWhether an attached actor still counts as held.

A zone's settle behaviour comes from a mode, with Custom starting from the standard values of 0.35 seconds and 20 units per second. These three report what is being applied after that resolution, rather than the fields in the Details panel.

Zone events

ASimFlowZone, dispatchers. All carry the actor.
DispatcherFires
On Actor EnteredThe moment an actor overlaps, before settling.
On Actor ExitedIt leaves.
On Actor SettledIt is genuinely put down. This is the one tasks listen to.

Bind On Actor Entered for hover feedback and On Actor Settled for anything that counts. A zone can also raise SimFlow.Event.Placed and SimFlow.Event.Removed on every flow, but only when its Broadcast Flow Events is ticked, which is off by default.

Highlighting the right object

Making a grabbable prop glow when it matches what the current task wants:

  1. Store the task's Actor Query where your prop can read it, or expose one on the prop itself.
  2. On overlap with the player's hand, call Match Actor Against Query with the prop and the flow instance.
  3. Switch on the result: green for Exact Match, amber for Related, nothing for No Match.

Amber on a near miss is worth the extra branch. It tells the trainee they are in the right family without telling them the answer.

When it misbehaves

SymptomCause
Every actor scores No MatchThe query uses a Blackboard Key and you passed null for Instance.
A query with no tags matches everythingAn empty query is legitimately satisfied by anything, and nothing logs.
Get Identity Tags is empty on a tagged actorThe tags are on a component the fallback does not reach. Add a SimFlow Identity component.
Get Settled Actors is empty while the object is visibly in the zoneIt has not settled: still held, still moving, or still attached with Require Detached on.
A widget passed to Match Actor Against Query never matchesA UUserWidget is neither an Actor nor an Actor Component. Pass the owning actor.
The zone's settle time does not match the Details panelThe mode is overriding it. Check Get Effective Settle Time.
