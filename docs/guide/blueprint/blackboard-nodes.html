Blackboard Nodes

Class
USimFlowBlackboard
Get a reference
Get Blackboard on the component, an instance, a task, a node or a condition
Target pin
The blackboard
Category
SimFlow | Blackboard

Use them for: reading and writing the per-flow key/value store from your own Blueprint.

What the blackboard is, which keys are reserved and how coercion works are covered in Blackboard & Values. This page is the node list.

Typed setters

USimFlowBlackboard, typed writes
NodeValue pin
Set Boolbool
Set Intint32
Set Floatfloat
Set StringFString
Set NameFName
Set VectorFVector
Set ObjectUObject reference

Each writes the value and sets its type in one node, which is why they beat Set Value plus a maker for a literal. Writing over an existing key of a different type replaces it, with no warning and a changed type.

Set Object stores a runtime-only reference. It is cleared on save.

Typed getters

USimFlowBlackboard, typed reads
NodeReturnsDefault pin
Get Boolboolfalse
Get Intint320
Get Floatfloat0.0
Get StringFStringempty
Get NameFNameNone
Get VectorFVectorzero
Get ObjectUObject— no default pin

The Default Value pin is what comes back when the key does not exist, which makes these safe on a flow that just started. Get Object is the exception with no default; it returns null.

A missing key never logs anything

It returns the default and moves on. A typo in a key name therefore produces no error anywhere. It produces a condition that is quietly always false, which is the single most expensive failure mode in the plugin.

Generic accessors

USimFlowBlackboard, type-agnostic
NodeNotes
Set ValueTakes a SimFlow Value.
Get ValueReturns an unset value when the key is missing.
Has ValueThe only way to tell "missing" from "set to the default".
Remove ValueDeletes one key.
Clear AllEmpties the blackboard.
Add To ValueAdds to the existing value, creating the key if absent.

Reach for these when the type is not known until runtime, or when you are copying values around without caring what is in them.

Has Value earns its place. Because every typed getter folds a missing key into its default, Get Int("Score", 0) returning zero cannot tell you whether the trainee scored nothing or the key was never written. Has Value can.

Score and serialisation

Score helpers and flattening
NodeNotes
Add ScoreAdds to the well-known Score key.
Get ScoreReads it.
To EntriesFlattens to an array. Strip Object References defaults to true.
From EntriesRestores. Clear First defaults to true.
Merge FromCopies every entry from another blackboard. Overwrite Existing defaults to true.

Merge From is what Sub Flow uses to hand state between parent and child. Call it directly to seed a fresh flow from a previous run's results.

On Value Changed

An event dispatcher, not a function. It fires on every write, carrying the key and the new value.

A score widget with no polling

  1. On Event Construct, get the flow and then Get Blackboard.
  2. Bind Event to On Value Changed.
  3. In the bound event, branch on Key == Score.
  4. On true, call Get Score and set your text.

When it misbehaves

SymptomCause
A getter returns the default and the key is definitely setKey names are FName and case-insensitive, so that is not it. Check for a trailing space, or print the blackboard with SimFlow.Debug 1.
Set Object survived into the next sessionIt did not. Object values are stripped on save and read back null.
Add To Value concatenated instead of addingThe key holds a String. "1" plus "1" is "11". Use Int for counters.
On Value Changed fires constantlyIt fires for every key. Filter on the key pin.
Changes made on a client vanishThe blackboard replicates server to client when Replicate Blackboard is on. Client writes are overwritten.
