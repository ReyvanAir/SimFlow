Node Reference

Set Blackboard Value Node

Class
USimFlowNode_SetBlackboard
Add via
Right-click → Data → Set Blackboard Value
Pins
In → Out
Category
Data

Use it for: seeding a key before a Branch reads it, resetting a counter between attempts, or recording which path a run took.

It writes a blackboard key inline in the graph, with no task object involved. Execution passes straight through.

Fields

USimFlowNode_SetBlackboard, Details panel
FieldTypeDefaultMeaning
KeyNameNoneWhich blackboard key to write.
ValueSimFlow ValueType NoneSet the Type first and the matching value field appears.
AddBoolfalseAdd to the existing value instead of replacing it.

Values can be Bool, Int, Float, String, Name, Vector or Object.

Set against Add

With Add off, the write replaces whatever was stored. With it on, numbers add, vectors add component-wise, and strings concatenate. The key is created if it does not already exist.

Strings concatenate

Adding "1" to "1" gives you "11", not 2. Use Int for counters. This is the single most common surprise on this node.

Adding to a missing key creates it with the delta as its value. Adding across mismatched types coerces on a best-effort basis rather than failing.

Two silent failures

Leaving Key as None still performs the write, under the literal key name None, with no warning. Leaving Value Type as None writes an unset value that conditions cannot usefully compare against. Neither announces itself.

A key-name typo has the same quiet quality: it produces a condition that is always false.

Node or task?

Use the node

  • A simple write in the graph, which is the usual case
  • You want the graph to stay readable

Use the task

  • You want it inside a Parallel Group
  • You want scoring or a Task Id attached to the write

Seed a key, then branch on it

Suppose a Branch checks Attempts at the top of the flow, before anything has written it.

  1. Seed the key

    Right after Start, right-click then Data → Set Blackboard Value. Set Key to Attempts, Value → Type to Int, Int Value to 0, and leave Add off.

  2. Increment on failure

    After each failed attempt, add another Set Blackboard Value node with the same key, an Int Value of 1, and Add on.

  3. Branch reliably

    The Branch can now compare Attempts, because the key always exists.

    Seeding saves you relying on Result When Key Missing, which is easy to forget is even there.

When it misbehaves

SymptomCause
A later condition never sees the valueThe key names differ. They are case-insensitive, but spelling is not forgiven. Print the blackboard with SimFlow.Debug 1.
A counter reads "111"The type is String with Add on, so it concatenated. Switch to Int.
The value vanished after loading a saveThe type is Object, and object references are stripped on save.
A key named None appeared in the debug overlayKey was left unset, and the write went through under that literal name.
