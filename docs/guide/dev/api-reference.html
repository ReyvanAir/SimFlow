Flows can be built entirely in code

All of the above is Blueprint-callable and safe at runtime, so a procedural flow generator is a supported use. SimFlowSampleBuilder.cpp is a complete worked example, reachable from the Tools menu or SimFlow.CreateSample.

Name constants

namespace SimFlowPins holds In, Out, Completed, Failed, Skipped, TimedOut, Default, LoopBody. Loop's Continue pin is USimFlowNode_Loop::ContinuePin.

namespace SimFlowKeys holds Score, Mistakes, LastResult, LastAnswerIndex, LastAnswerCorrect, WrongAttempts, CurrentStep.

Use the constants

They are exported with SIMFLOWRUNTIME_API, so a game module can link against them. A string literal that drifts from the constant produces a pin that silently never connects.

Native gameplay tags

In namespace SimFlowTags:

Event, Event_Generic, Event_Interact, Event_Grab, Event_Release, Event_ButtonPressed
Sample_GrabExtinguisher, Sample_PullPin        // used by the sample flow only

Declare your project's own with UE_DECLARE_GAMEPLAY_TAG_EXTERN and UE_DEFINE_GAMEPLAY_TAG, or in the Gameplay Tags project settings, and raise them with BroadcastFlowEvent. Keep them out of the SimFlow. hierarchy, which belongs to the plugin.
